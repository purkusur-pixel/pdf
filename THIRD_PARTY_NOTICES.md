# Third-party software / Üçüncü taraf yazılımlar

This project bundles the following open-source libraries and fonts in `html/libs/` and `html/fonts/`.
Full license texts are in [`licenses/`](licenses/).

Bu proje aşağıdaki açık kaynak kütüphaneleri ve yazı tiplerini `html/libs/` ve `html/fonts/` içinde barındırır.
Lisans metinlerinin tamamı [`licenses/`](licenses/) klasöründedir.

| Package / Paket | Version / Sürüm | License / Lisans | Used for / Kullanım |
|---|---|---|---|
| [PDF.js](https://github.com/mozilla/pdf.js) (`pdfjs-dist`) | 3.11.174 | Apache-2.0 | PDF rendering, text extraction / görüntüleme, metin çıkarma |
| [pdf-lib](https://github.com/Hopding/pdf-lib) | 1.17.1 | MIT | Merge, split, edit, stamp / birleştirme, bölme, düzenleme |
| [JSZip](https://github.com/Stuk/jszip) | 3.10.1 | MIT or GPL-3.0 (MIT used) | ZIP output / ZIP çıktısı |
| [docx](https://github.com/dolanmiu/docx) | 8.5.0 | MIT | PDF → Word |
| [mammoth](https://github.com/mwilliamson/mammoth.js) | 1.6.0 | BSD-2-Clause | Word → PDF (DOCX reading) |
| [html2pdf.js](https://github.com/eKoopmans/html2pdf.js) | 0.10.1 | MIT | Word/Excel → PDF |
| [PptxGenJS](https://github.com/gitbrent/PptxGenJS) | 3.12.0 | MIT | PDF → PowerPoint |
| [SheetJS CE](https://sheetjs.com) (`xlsx`) | 0.18.5 | Apache-2.0 | Excel → PDF |
| [jsPDF](https://github.com/parallax/jsPDF) | 2.5.1 | MIT | Protect PDF / şifreleme |
| [Inter](https://rsms.me/inter/) (`@fontsource/inter`) | 5.1.0 | OFL-1.1 | UI font / arayüz yazı tipi |
| [Dancing Script](https://github.com/impallari/DancingScript) (`@fontsource/dancing-script`) | 5.1.0 | OFL-1.1 | Typed signatures / yazılı imza |
| [Caddy](https://caddyserver.com) (Docker image) | 2.8 | Apache-2.0 | Web server + automatic HTTPS / web sunucusu + otomatik SSL |
